Capture Ideas

User Guide - v1.1.0
BUILT

What this app does

Capture Ideas lets you browse the app-ideas backlog and add new ideas from any device. It's the same board as Ideas.html on the laptop, made phone-friendly and given a capture form. When you add an idea, it's written straight into Ideas.md - the one true backlog file - by committing to GitHub in the background.

First run: set your PIN

The first time you open the app it asks you to create a 4-6 digit PIN. Enter it, confirm it, and you're in.

  • The PIN is stored only on that device, as a one-way hash - never in plain text, never in the code.
  • On later visits you just enter the PIN. It's remembered for the session; fully closing the app asks again.
  • Forgot it? Tap Forgot PIN? Reset on the lock screen to set a new one. This doesn't touch your ideas - they live in the repo, not on the device.
Honest note: the backlog repo is public, so the PIN is a convenience latch to keep casual eyes off the app - not real security. The backlog files can be read directly on GitHub, so don't put anything sensitive in the backlog.

Browsing the backlog

Once unlocked you see every idea, grouped into Simple / Medium / Complex. Each card shows its complexity, category, status, and (for built apps) a version tag.

  • Search - type to filter across name, category, description, scope and status.
  • Complexity / Status - tap a segment to filter; tap All to clear that one.
  • Category - pick from the dropdown.
  • Clear filters - resets everything back to All.
  • Tap a card - opens that idea's overview (or its backlog summary if no overview page exists yet).

Capturing a new idea

  1. Tap + Add idea (top-right of the header).
  2. Fill in the name and a short description (both required).
  3. Pick the complexity and category; optionally add scope (v1).
  4. Leave status as Idea (or change it if you're recording something already underway).
  5. Tap Save to backlog. You'll see a confirmation, and the new card appears in its tier.

Behind the scenes this adds a correctly-formatted row to the right tier table in Ideas.md and commits it. Pipe characters in your text are escaped automatically so the table can't break.

Editing and deleting an idea (new in v1.1.0)

Every idea now has two small icons for quick changes. On a laptop they appear in the top-right corner of a card when you hover over it; on a phone or tablet they're always visible. The same two icons also sit in the header when you open an idea's overview.

Edit (pencil icon)

  1. Tap the pencil on the card (or in the open overview).
  2. The form opens pre-filled with that idea's details; the title reads Edit idea.
  3. Change whatever you need - name, complexity, category, description, scope or status.
  4. Tap Update idea. The matching row in Ideas.md is updated in place. If you change the complexity, the idea moves to the correct tier automatically.

Delete (trash icon)

  1. Tap the trash icon on the card (or in the open overview).
  2. A confirmation appears - this guards against accidental deletes.
  3. Confirm, and the idea's row is removed from Ideas.md and the board refreshes.
Editing and deleting write to the backlog, so they need a GitHub token set in Settings (see below) and an internet connection. Browsing still works without one. Both actions use the same safe retry as capturing, so a laptop edit and a phone edit can't silently clobber each other.

Settings: connect it to GitHub

Browsing works with no setup. To save ideas from a device, that device needs a GitHub token once. Tap the gear icon (top-right) to open Settings.

Get a token

  1. On GitHub: Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access: only the IdeasBacklog repo.
  3. Permissions: Contents → Read and write (nothing else needed).
  4. Set an expiry (e.g. 90 days), generate, and copy it.

Enter it

  • Owner / Repository / Branch - pre-filled as isaacgera / IdeasBacklog / main; change only if yours differ.
  • Token - paste it and tap Save settings. It's stored only on that device and is never committed.
  • Remove token - clears it from the device. Change PIN - sets a new PIN.
A token is a real credential. Keep it scoped to just this repo with an expiry, and if a device is lost, revoke the token on GitHub - it dies instantly and nothing else is exposed.

Install it as an app (PWA)

  • iPhone/iPad (Safari): Share → Add to Home Screen.
  • Android (Chrome): menu → Install app / Add to Home screen.
  • Desktop (Chrome/Edge): the install icon in the address bar.

Installed, it opens full-screen from your home screen and works offline for browsing.

Working offline

The last-loaded board is available offline. If you capture an idea while offline (or before adding a token), it's queued on the device and committed automatically once you're back online and a token is set - you'll get a "synced" confirmation.

Keeping laptop and phone in step

The phone and the laptop both work on the same Ideas.md in GitHub. To avoid them drifting:

  • On the laptop, git pull before editing the backlog and git push after.
  • If two edits ever clash, the app re-reads the latest file and retries, so a capture won't overwrite a laptop change.
