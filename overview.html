Capture Ideas

Idea Overview - one-page summary
BUILT - v1.0.0
Category: Utility Complexity: Simple Installable PWA

What it is

A mobile-first, installable web app (PWA) that sits on top of the app-ideas backlog. It is the same board you already know from Ideas.html, made responsive for the phone and given the ability to capture new ideas on the go. New ideas are committed straight into Ideas.md - the single source of truth - through the GitHub API, so the phone edits the real backlog rather than a separate copy. Hosted from the public IdeasBacklog repo on GitHub Pages.

Who it's for

Anyone who curates an app/idea backlog and wants to add to it away from the desk - on the sofa, on the train, mid-conversation. Built for Isaac's own workflow, where ideas arrive at inconvenient moments and the backlog lives on the laptop in Kiro.

Why it's useful

Ideas are perishable - if you can't capture one the moment it lands, it's often gone. The backlog previously could only be edited on the laptop. This closes that gap: browse the whole board (filter by complexity, status and category, or search) and add a new idea from your phone in seconds, with it landing in the same Ideas.md the laptop uses. No copy-paste, no second list to reconcile.

How it helps

  • Browse anywhere - the full board, responsive and touch-friendly, with light/dark themes.
  • Capture in seconds - a simple form (name, complexity, category, description, scope) writes a correctly-formatted row into the right tier table.
  • One source of truth - commits go to Ideas.md via the GitHub API, with a safety check so concurrent edits can't silently overwrite each other.
  • Works offline - installed as a PWA; if you're offline, a capture is queued locally and synced automatically when you're back online.
  • Light PIN gate - a device-set PIN keeps casual eyes off the app.

Note: the repo is public, so the PIN is a soft UI gate, not data security - the backlog files are readable on GitHub. Nothing sensitive should go in the backlog.
