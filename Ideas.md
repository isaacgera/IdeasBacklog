# App Ideas Backlog

A running list of app ideas grouped by complexity. Use this to pick up existing work or start something new. Keep it lean; tweak the format as needs change.

**Complexity tiers**
- **Simple** — single page, no backend, minimal state. A session or two.
- **Medium** — multiple views/features, local persistence, maybe a PWA. Several sessions.
- **Complex** — richer data model, integrations/APIs, offline sync, or multi-role logic. Ongoing.

**Category:** Finance | Productivity | Health | Home | Learning | Utility | Work | AI/Agents | Devotional
**Status:** Idea | In Progress | Built | Parked

## AI features inside apps — Bucket B (parked for later)
Agent-like features to add *into* backlog apps once we've built the base app. These need a model API (OpenAI / Cohere / Groq / Hugging Face) and light guardrails.

> **Build note (Sep 2026):** These runtime, model-reasoning-over-data features are the natural home for the **AWS Bedrock / AgentCore** power (hosted agents with a cloud runtime), unlike the local Kiro custom agents (e.g. New App Scaffolder) which just run inside the IDE over local files. Consider AgentCore here when we pick one of these up — and note it means revisiting the local-first/no-cost stance (cloud runtime, IAM, billing).

- **Stock Analysis Copilot** — walks the 10-min checklist and writes a plain-English verdict (pairs with Company Analysis Workbench).
- **Finance Insights agent** — answers questions over your local WealthOrah data (spending drift, portfolio concentration).
- **Journaling Prompt agent** — adapts prompts to recent entries; gentle reflections.
- **Recipe/Meal agent** — suggests a week's meals from what's on hand and builds the grocery list.
- **Study Coach agent** — generates flashcards from notes and schedules reviews.
- **Client Comms agent** — booking/reminder/FAQ helper (pairs with Small Business Invoicer). Inspired by the "AI agents for local businesses" idea set.

## Reference — free APIs by purpose
Handy when a data-dependent app is ready to wire up a live source. Free tiers, personal use.
- **Market/finance data:** Alpha Vantage, Finnhub, Twelve Data (stocks/indices; US strong, some IN); CoinGecko (crypto).
- **AI / NLP:** OpenAI, Cohere, Hugging Face, Groq (fast/low-cost inference).
- **Weather:** Open-Meteo (no key needed), OpenWeatherMap.
- **News:** NewsData.io, The Guardian API.
- **Email/notifications:** Mailgun, Brevo, Pushover.

*Note:* API keys are secrets. When we build these, keep keys out of the repo (never commit them) and out of client-side code where possible.

| Angular | TS | Large, structured, long-lived | Good | Yes (CLI, heavier) | High | Good | Moderate |
| Next.js (React) | JS/TS | Content+app hybrids, SEO/SSR | Excellent | Yes (Node) | Med-High | Good | Easy-Mod |
| Astro | JS/TS + any | Content-rich, mostly static, fast | Very good (islands) | Yes (Node) | Low-Med | Good | Easy |
| Flutter | Dart | True cross-platform (mobile/web/desktop) | Excellent (60fps) | Yes (Flutter SDK) | Med-High | OK (shines mobile) | Moderate |

**Add-on layers (pair with any of the above):**
- **Tailwind CSS** — fast consistent styling. **GSAP** — pro timeline animations.
- **Framer Motion** — springy React animations. **Three.js / R3F** — 3D/WebGL.
- **D3.js / Chart.js / ECharts** — rich data viz (great for the finance apps).
- **shadcn/ui, MUI, Chakra** — ready-made accessible React components.

*Takeaways:* Svelte = rich visuals while staying light. Finance apps often hinge on the
charting layer more than the framework. Astro suits content-heavy pages. Every framework
option adds a build step + Windows tooling vs the current no-build workflow — weigh that
against what the app actually needs.
